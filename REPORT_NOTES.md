# Что понадобится для отчёта ДЗ 1

Вариант: 3
Предметная область: запись на приём к специалисту
Сущности: специалист, услуга, слот, запись

План:
1. Запустить сервис.
2. Проверить три обязательных сценария интерфейса.
3. Запустить модульные тесты.
4. Зафиксировать команду наполнения малым и рабочим объёмом.
5. Получить фактическое количество записей в PostgreSQL.
6. Выполнить не менее 20 повторов каждой операции после прогрева.
7. Зафиксировать p50 и p95.
8. Для выбранных операций измерить время в приложении и PostgreSQL.
9. Сформулировать минимум 3 гипотезы узких мест с числами из замеров.
